# 05-2_访问控制

在C++类定义中，可以用成员访问控制修饰符``public``, ``private``, ``protected``来描述对类成员的访问限制。

## 01 public
成员的访问**不受限制**，在程序中的**任何地方**都可以访问一个类的public成员。

## 02 private
成员只能在**本类和友元**中访问。

>[!warning]
>C++类成员的默认访问控制是private（结构struct、联合union中默认为public）。

## 03 protected
成员只能在**本类、友元和派生类**中访问。

```cpp
class A {
    int m, n;
public:
    int x;
    void f();
private:
    int y;
    void g();
protected:
    int z;
    void h();
public:
    void f1();
}
```
