# 05-5_对象的初始化和消亡前处理

## 01 构造函数
在使用对象前，需要对它的数据进行初始化。由于数据成员一般是**私有的**，因此不能通过对象直接对它们赋值。我们可以在对象类中提供一个实现**对象初始化的**的普通成员函数，创建对象后，通过**调用该函数**来初始化对象。

为了解决对象的初始化问题，在 C++ 中提供了一种用来对对象进行初始化的**特殊的成员函数 — 构造函数**。

### 01 定义
构造函数（constructor）是指在对象类中定义或声明的**与类同名、无返回值类型**的成员函数。

在创建对象时，系统首先为对象分配空间，然后**自动调用**对象类的构造函数来初始化对象。
```cpp
class A{
    int x;
public:
    A() {x = 0;}
};
